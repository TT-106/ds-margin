# DS Margin · 留白

DS Margin 0.5.2 为 DeepSeek 网页提供项目侧栏、划词旁问、本地书库、目录、收藏、提示词和草稿恢复。旁问使用当前登录账号的原站聊天界面。

阅读区采用书页排版，工具集中在右侧。窗口宽于 1100px 时，打开工具面板会为面板留出位置；窄屏使用带遮罩的弹层。

打开聊天页时先显示纸色背景。识别到原站输入框后即可使用工具栏，即使页面仍在解析。若 2.5 秒内未就绪，页面自动恢复显示。旁问先显示正文，并按需排版 Markdown。遇到完整公式时才加载 KaTeX。

## 安装

安装现成版本不需要 Node.js，也不需要 API Key。

1. Chrome 地址栏打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`。
2. 开启页面中的「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择 **`D:\下载\margin\ds-margin\dist`** 文件夹。该文件夹内应直接包含 `manifest.json`。
4. 打开或刷新 [DeepSeek](https://chat.deepseek.com/)，正常登录。进入聊天页后，右侧显示工具栏。
5. 可在浏览器扩展菜单中固定「DS Margin · 留白」图标，用于快速开关与主题切换。

也可以将 `DS-Margin-0.5.2.zip` 解压到固定目录，选择内含 `manifest.json` 的文件夹。

请保留所加载的目录。更新时覆盖同一路径下的扩展文件，在扩展管理页面点击刷新，再刷新 DeepSeek 页面。重装或改变目录前先备份本地数据。

## 使用

左侧「项目」用于组织和继续原站对话。首次使用从左栏选择项目，之后会记住上次打开的视图。选择一个项目后，「新建对话」会显示目标项目，并在识别到本次首发和原站新会话后自动归入。识别中断时，可在原对话打开后从「当前会话」手动移入。项目内可置顶、移入或移出会话，窄屏点「会话项目」展开抽屉。

「搜索会话」默认搜索当前项目标题，可切到「项目与已加载历史」。通过「原站历史」可以继续查找更早的对话，正文搜索在右侧书库。项目索引独立于自动正文收录。

桌面右侧有「目录」「书库」「更多」和 `m.` 阅读设置。「提示词」「收藏」「专注模式」和「命令」在「更多」内。点击聊天页空白处可收起侧栏面板，窄屏可点击遮罩。也可按 `Esc` 或点击关闭键。

| 入口 | 用途 |
| --- | --- |
| 目录 | 在当前已加载消息中搜索和跳转；切换「全部消息」后可收藏整条回答 |
| 书库 | 搜索本地已收录正文，查看快照，按项目、标签与置顶整理 |
| 提示词 | 使用八种内置模板，或新建模板；`{{变量名}}` 可在使用时填写 |
| 收藏 | 保存选中文字或整条消息，添加备注，定位来源 |
| 专注 | 收起已识别的原站侧栏；再次点击恢复 |
| 设置 | 调整主题、字号、行高、内容最大宽度和消息间距，管理本地数据 |

`Alt+K` 打开命令面板，`Alt+O` 打开目录，`Esc` 关闭当前面板。命令面板显示最近对话，支持方向键选择和回车执行。快捷键可在设置中关闭。

在原生输入框的行首输入 `/` 可打开提示词菜单。继续输入标题筛选，按方向键和回车选择。有变量时会在输入框上方打开表单，例如「解释一个概念」会请你填写「概念」。点「填入输入框」后可检查内容，再用原站按钮发送。

草稿恢复会在当前光标处插入文字。两标签页编辑同一对话时，会提示草稿冲突。

需要导出当前加载的消息时，进入设置选择 Markdown 或 JSON。查看书库中的快照时，也可以导出该份快照。

## 划词旁问

1. 在一条已打开的 DeepSeek 对话中选中一段正文，点「旁问」即可快速讲解。需要搜索时点「联网旁问」。两种旁问都会关闭深度思考。浮层可拖动，点击页面空白处收起。
2. 扩展确认独立执行窗口已经最小化后，才打开 DeepSeek 并提交选中文字和可识别的所在段落。主窗口保留原标签和焦点，生成中的正文会逐段显示在浮层里。若 Chrome 在提交前恢复了执行窗口，本次会停止并允许手动重试。首答完成后可继续追问，并可单独选择联网。
3. 已保存的旁问在引用原词下持续显示一排细点。收起浮层或刷新页面后，点状标记仍会保留，点击原词即可重开问答。同一处多条旁问默认打开最新一条，也可点左栏主会话旁的「旁问 N」查看全部记录，原文未加载或已变化时仍可阅读保存的摘录与问答。
4. 若提示发送状态需核对，可用「打开原网页会话」检查。原站的请求标记和相邻答复都能读到时，扩展会找回回答。等待核对期间暂停续问。
5. 在装有扩展的 DeepSeek 网页中删除主会话。原站确认成功后，DS Margin 会清除主会话下的旁问及其专属分支，并结束被清理的关联旁问。子树外仍引用的会话及其下属旁问会保留。

旁问问答与引用保存在当前浏览器配置的本地数据库。它在 DeepSeek 上有独立会话，用于保留追问上下文。发送的引用和问题由 DeepSeek 处理。级联清理后，已确认归属的官网旁问副本仍在 DeepSeek 账号中，DS Margin 会继续把它们隐藏在左栏之外。

## 阅读外观

- 阅读正文、输入框、面板标题和书名使用 **Lora / Noto Serif SC**。导航、按钮、设置与数值使用 **Poppins** 和系统中文字体，代码使用等宽字体。三行以内的纯文本片段使用阅读字体。
- 三种开源字体均随扩展打包，无需运行时访问字体 CDN。字体许可证位于 `dist/fonts/OFL-*.txt`。
- 侧栏和顶栏连成一块磨砂面，右侧面板和工具栏也会透出背景光影。输入框聚焦使用墨色描边，完成、等待和出错各有对应的图标和颜色。

## 本地记录的范围

自动收录默认开启，仅保存你打开过的对话中已经加载、且能识别出稳定消息 ID 的正文。官网采用虚拟列表：滚动离开屏幕的已观察消息会保留在本地，尚未加载的内容不会自动抓取。

思考过程、附件正文、图片文件和登录凭据不进入归档。收藏保留当时的原文；若来源消息被编辑、重新生成或暂未加载，会提示无法精确定位，不跳转到其他消息。

当前页面导出仅包含当时加载的内容。本地快照可能积累先后观察过的不同回答分支，不代表账号完整历史；导出中也会标明这个范围。

设置保存在 `chrome.storage.local`。对话、收藏、提示词、草稿和旁问保存在扩展的 IndexedDB 中。

本地项目和书库按浏览器配置保存。同一浏览器配置切换 DeepSeek 账号时，仍可看到本地项目与书库。使用独立浏览器配置可以隔离本地记录。

## 备份、删除与关闭

- 在「设置」备份本地数据可下载 v4 JSON，包含项目、旁问、归档、收藏、模板、草稿和收录状态。
- 升级会把旧书库文件夹迁移为项目。导入支持 v1–v4，保留当前设置，遇到已有会话时优先采用当前项目归属。升级后的数据库需要 0.5.0 或更新版本读取。
- 删除本地归档只删除正文副本并暂停收录。项目仍可用于续聊。删除项目只解除分组。在原站删除会话时，收到成功确认后才清理项目索引和对应的旁问记录。
- 清空本地数据会移除项目、归档、收藏、模板、草稿、旁问及旧版任务数据，并暂停收录已记录的对话。
- **关闭增强**：浏览器扩展图标 → 关闭「启用界面增强」。页面恢复原站外观，本地记录仍然保留。
- **卸载**：浏览器会删除此扩展的本地数据，请先导出备份。

## 构建与测试

要求 Node.js 22.12+ 和 npm。在 PowerShell 中：

```powershell
cd 'D:\下载\margin\ds-margin'
npm.cmd ci
npm.cmd run build
npm.cmd test
npm.cmd run test:browser
npm.cmd run test:projects
npm.cmd run test:side-questions
```

如测试提示缺少浏览器，先运行 `npx.cmd playwright install chromium`。测试脚本也会使用本机已有的 Playwright Chromium 缓存。

```powershell
# 只读检查官网入口，不发送真实消息
npm.cmd run test:live

# 生成可解压加载的安装包
npm.cmd run package
```

浏览器测试加载真正的 MV3 扩展，在独立配置和受控的 DeepSeek 结构测试页中操作。结果和预览位于 `output/playwright/0.5.2/`。

旁问延迟对照使用固定构建快照。DOM 和原生流分别测量，计数探针独立运行。

```powershell
node scripts/side-latency-benchmark.mjs output/side-latency-20261111/baseline/dist output/side-latency-20261111/candidate/dist output/side-latency-20261111/rerun 12
```

具体验证结果及未验证项见 [TESTING.md](TESTING.md)。

## 适配说明

站点选择器集中在 `src/content/adapter.ts`。旁问的网页执行、原站流式读取和发送状态恢复集中在 `src/sidequestions/`。

如果原站更新后目录为空或某个工具失效，可先从扩展图标关闭增强，保留正常聊天；随后更新适配器。扩展更新后出现连接提示时，刷新 DeepSeek 页面即可。
