DS Margin 0.5.2 · 旁问响应优化

1. 在 Chrome 打开 chrome://extensions/，或在 Edge 打开 edge://extensions/。
2. 开启“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择本文件所在的文件夹。该文件夹中应直接包含 manifest.json。
4. 刷新 https://chat.deepseek.com/ 并登录，左侧使用项目，右侧使用阅读工具栏。

无需 Node.js 或 API Key。Alt+K 打开命令面板，Alt+O 打开目录。

字体：Lora / Poppins，中文正文为 Noto Serif SC。宽屏打开面板时聊天区让位；窄屏使用带遮罩的面板。
功能：项目、目录、本地搜索与归档、收藏和备注、提示词、草稿恢复、Markdown / JSON 导出。
选择项目后新建对话，确认原站首发后自动归组。原站历史仍可从左侧直接打开。窄屏点「会话项目」。
升级前可备份本地数据。旧书库文件夹会迁移为项目，升级后的数据库需要 0.5.0 或更新版本读取。

划选一条消息内的文字，点击「旁问」即可快速讲解，也可选「联网旁问」。两种旁问均关闭深度思考。
拖动顶部可移动浮层，点击页面空白处收起。
讲解在独立的最小化 Chrome 窗口中执行，主窗口保留原标签和焦点。首答完成后可继续追问。
刷新后点击左栏对应主会话旁的「旁问 N」找回。需要核对发送状态时，可从浮层打开原网页会话。
在此网页删除主会话并得到 DeepSeek 的成功确认后，扩展会清除主会话及专属分支的本地旁问。仍被其他会话引用的子会话及其下属旁问会保留。原网页旁问副本保留在 DeepSeek 账号中。

桌面右侧有目录、书库、更多和 m. 阅读设置。窄屏用「工具」打开其余入口。
点击页面空白处可收起侧栏面板。在聊天输入框行首输入 / 可选提示词，填写变量后点「填入输入框」。
本地归档默认开启，仅保存已打开对话中已加载的正文；不是全部历史备份。
思考过程与附件正文不归档。切换 DeepSeek 账号不会隔离当前浏览器的本地书库。

可以从浏览器工具栏的扩展图标关闭增强，恢复原站外观。
覆盖旧文件后，请先在 Chrome 扩展管理页重新加载「DS Margin · 留白」，再刷新 DeepSeek，确保后台与页面使用同一版本。
卸载扩展会删除其本地数据，请先在“设置”中导出备份。

测试已覆盖独立测试页面；真实官网登录后的聊天流程尚未进行账号验收。
完整源码与说明位于 ds-margin 项目目录的 README.md、TESTING.md。
